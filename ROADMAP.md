# Roadmap

## Phase 1 — intelligence foundation

- Product intake and CSV import
- Append-only evidence and provenance
- Unit economics and order-volume scenarios
- Explainable scoring and penalties
- Audited pipeline decisions
- Supplier comparisons and validation experiment records
- Local dashboard, migrations, tests, and documentation

## Phase 1 hardening

- Versioned product/assumption edit service — completed in Work Order 002
- Multiple named scoring profiles (the active weight set is already persisted and audited)
- Evidence correction/supersession links
- CSV templates, export, backup/restore, and deletion/retention workflows
- PostgreSQL integration tests and accessibility/user acceptance review
- Local authentication before any shared deployment

## Later, only after foundation validation and explicit approval

- Read-only authorized data connectors with rate limiting and source snapshots
- Experiment analysis and cohort comparison
- Review queues and role-based approvals
- Storefront/export integrations behind human approval gates

Excluded until separately approved: autonomous ordering, publishing, supplier contact, advertising spend, customer-facing AI, or paid infrastructure.
